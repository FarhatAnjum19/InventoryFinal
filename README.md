InventoryFinal
===============

This repository contains a simple inventory management project with a Node.js/Express backend and a Vite/React frontend.

Structure
---------

- `backend/` — Express server, API routes, models, and services.
- `frontend/` — React app (Vite) with components, pages, and assets.

Quick start
-----------

Backend (from repository root):

1. Install dependencies and run:

   cd backend
   npm install
   npm start

Frontend:

1. Install dependencies and run (from repo root):

   cd frontend
   npm install
   npm run dev

Notes
-----

- There is no top-level README previously; this file provides a brief overview and run instructions.
- For backend configuration, see `backend/.env` and `backend/src/config/db.js`.
